List users

GET /users returns the people in your workspace. The users are returned in the data array of the response.

Each user object has an id, an email, a name and last_seen, the time the user last used Example App.

Example response: {"data": [{"id": 17, "email": "ana@example.com", "name": "Ana", "last_seen": "2026-10-01T10:00:00Z"}], "next": null}
